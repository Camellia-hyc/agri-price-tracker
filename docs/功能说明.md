# 功能说明

> **本文档目的**:面向使用者与验收者,逐页说明交互逻辑、筛选规则、指标含义与页面间跳转关系。所有描述均对应实际实现(源码 `src/pages/`、`src/components/`)。

## 1. 全局导航与布局

- 顶部 Header 固定三个入口:**首页**(`/`)、**价格对比**(`/compare`)、**趋势分析**(`/trend`),当前页高亮。
- 桌面端为横向导航;移动端(<768px)折叠为汉堡菜单。
- 所有页面首次进入都会并行请求产品、市场、价格三份数据,加载期间显示"数据加载中…",请求失败显示错误文案。
- 访问不存在的地址进入 404 页,可一键返回首页。

## 2. 首页

首页自上而下三段:品牌区(标题 + 搜索框)、按分类浏览、价格异动。

### 2.1 搜索框

- 占位提示:"搜索产品或市场,如:猪肉、新发地"。
- 匹配规则(不区分大小写):
  - 产品:名称或 ID 包含关键词,如输入"猪肉"或 "pork";
  - 市场:名称、城市或 ID 包含关键词,如"新发地"、"北京"。
- 每组最多展示 **5** 条建议;两组均无结果时显示"暂无匹配"。
- 交互细节:建议项用 `onMouseDown` 触发跳转(先于输入框 `blur`),避免下拉先收起导致点击失效。
- 点击产品建议 → 跳转 `/trend?product=产品ID`(趋势页自动选中该产品);点击市场建议 → 跳转 `/compare?market=市场ID`(对比页自动选中该市场)。

### 2.2 分类入口

- 五大分类:**蔬菜、水果、粮油、肉禽蛋、水产**,每张卡片显示该分类下的产品数量(共 20 种,每类 4 种)。
- 点击分类 → 跳转 `/trend?category=分类名`,趋势页自动选中该分类的前 3 种产品。

### 2.3 价格异动(涨跌异动榜)

- 并排两张卡片:**涨幅榜 Top5**、**跌幅榜 Top5**。
- 计算口径(首页 `Home.tsx` 中的聚合逻辑):
  1. 取数据中的**最新一天**与**前一天**;
  2. 对每个产品,计算这两天的**全市场均价**(该日所有市场报价的平均值);
  3. 涨跌幅 = (最新日均价 − 前一日均价) / 前一日均价 × 100%;
  4. 按涨跌幅排序,涨幅取前 5、跌幅取前 5;无上涨/下跌品种时显示"暂无上涨品种 / 暂无下跌品种"。
- 每行显示:排名、产品名、最新日均价(元/公斤)、涨跌幅。**红色向上箭头 = 涨,绿色向下箭头 = 跌**(国内行情习惯)。
- 点击任意一行 → 跳转 `/trend?product=产品ID`。

## 3. 价格对比页

### 3.1 筛选器(产品 / 市场 / 日期)

| 筛选项 | 规则 |
|---|---|
| 产品 | 多选,**上限 3 个**;达上限后未选中的产品置灰不可再选;按"全部 + 五分类"Tab 过滤产品列表 |
| 市场 | 多选,**上限 6 个**;按钮显示城市名(悬停可见全称);达上限后同样置灰 |
| 日期 | 单选,原生日期选择器;可选范围被限制在数据实际日期范围内;**默认选中最新一天** |

- 默认选中:猪肉、鸡蛋、大白菜 3 种产品;北京新发地、上海江桥、广州江南、成都农产品中心、西安欣桥 5 个市场(便于首次进入即有内容)。
- 选择顺序会被保留,图表系列与表格列均按选择顺序排列。
- 产品与市场全部取消时,显示"请至少选择 1 个产品和 1 个市场"。

### 3.2 柱状对比图

- 类型:分组柱状图;**X 轴 = 市场(城市名),每个产品一条系列**(柱子)。
- 悬停显示数值与"元/公斤"后缀;柱顶圆角;最多 3 产品 × 6 市场 = 每组最多 3 根柱。
- 某市场当日无某产品报价时,该位置不画柱(数据为 `null`)。

### 3.3 价格明细表

- 结构:**行 = 市场**(显示市场全称 + 所属地区),**列 = 产品**(表头带"(元/公斤)")。
- **高亮规则**:对每一产品列,该列所有市场中的**最低价标绿色加粗,最高价标红色加粗**;当整列价格相同(最低 = 最高)时不做高亮,避免整列全亮。
- 缺数据显示"—";表格底部有一行**"均价"**,为每列所有市场价格的算术平均。
- 图表与表格上方均有卡片说明,如"绿色为当日最低价,红色为当日最高价"。

### 3.4 配色约定(全站一致)

涨 = 红色,跌 = 绿色,与国内行情软件习惯一致(技术实现:涨用 `text-destructive`,跌用 `text-primary`,本项目 primary 为绿色系)。

## 4. 趋势分析页

### 4.1 筛选器(产品 / 市场 / 时间范围)

| 筛选项 | 规则 |
|---|---|
| 产品 | 多选,**上限 3 个**;交互与对比页一致(共用 `ProductPicker` 组件) |
| 市场 | **单选**(一次只看一个市场的走势) |
| 时间范围 | 单选:近 7 天 / 近 30 天 / 近 90 天 / 近 1 年,**默认近 30 天**;以数据最新一天为终点向前截取 |

- 默认选中:猪肉、鸡蛋、大白菜;北京新发地市场。
- 首页跳转带来的 URL 参数会自动初始化选择:`product=ID` 选中单个产品;`category=分类` 选中该分类前 3 种产品(与 3 个上限保持一致)。

### 4.2 统计卡片

每个选中的产品一张卡片,指标含义:

| 指标 | 含义 | 计算方式 |
|---|---|---|
| 最新价(大号数字) | 区间内最后一天的报价 | 时间范围内最后一条记录 |
| 区间涨跌 | 区间首日 → 末日的涨跌幅 | (末价 − 首价) / 首价 × 100%,红涨绿跌,持平显示灰色横线 |
| 最高 / 最低 | 区间内报价的最高值 / 最低值 | 区间内所有记录取 max / min |
| 均价 | 区间内所有报价的算术平均 | 区间记录求和 ÷ 天数 |

### 4.3 价格走势折线图

- 类型:多产品折线图;X 轴 = 日期,每条产品线一种颜色(色板与柱状图一致)。
- 设计要点:
  - 曲线平滑(`smooth`),不显示数据点标记,避免 90 个点过于密集;
  - **Y 轴不从 0 起**(`scale: true`):各产品单价差异大(如鸡蛋约 10 元 vs 牛肉约 68 元),从 0 起会导致低价产品走势被压平;
  - 某产品在某日期缺数据时,曲线在该处断开(null)。
- 卡片标题显示:市场名 · 起止日期 · 单位(元/公斤)。

## 5. 页面间跳转关系

| 起点 | 动作 | 目标页面 | URL 参数 |
|---|---|---|---|
| 首页搜索框 | 点击产品建议 | 趋势分析 | `product=产品ID` |
| 首页搜索框 | 点击市场建议 | 价格对比 | `market=市场ID` |
| 首页分类卡片 | 点击分类 | 趋势分析 | `category=分类名` |
| 首页异动榜 | 点击行 | 趋势分析 | `product=产品ID` |
| 顶部导航 | 点击 | 三个页面直达 | 无 |

跳转参数通过 `useSearchParams` 读取,目标页在数据加载完成后按参数初始化选择。

## 6. 其他状态

- **加载中**:数据未返回时,内容区显示"数据加载中…";路由懒加载切换页面时内容区显示"页面加载中…"(Header/Footer 不闪烁)。
- **加载失败**:显示"数据加载失败:{原因}"。
- **404**:大号"404" + "页面不存在",附"返回首页"按钮。

## 7. 移动端适配

- Header 折叠为汉堡菜单(展开后为竖向导航,点击后自动收起);
- 价格明细表在窄屏下容器横向滚动(`overflow-auto`),不破坏布局;
- 所有产品/市场选择按钮 `flex-wrap` 自动换行;
- 统计卡片栅格自适应:手机 1 列 → 平板 2 列 → 桌面 3 列;
- 图表监听窗口 `resize` 自动重绘。
