## 1. 引言

### 1.1 编写目的

本报告从技术、经济、操作、法律与进度等维度,对"农价通"农产品价格对比与趋势分析系统进行可行性研究与论证,为项目立项与后续开发提供决策依据。

### 1.2 项目背景

农产品批发价格信息分散于各地批发市场、政府监测平台与电商渠道,普通消费者、餐饮采购人员与小型商户缺少一个**跨市场、跨品类**便捷比价与价格走势查询的工具。本项目拟构建一个基于 Web 的农产品价格对比与趋势分析系统:

- **价格对比**:同一日期、不同批发市场、多产品的价格横向对比(柱状图 + 明细表);
- **趋势分析**:指定市场内产品价格的历史走势(折线图 + 统计指标);
- **快捷入口**:产品/市场搜索、分类浏览、价格异动榜单。

本项目同时作为《软件工程》课程设计项目,完整实践"可行性研究 → 需求分析 → 总体设计 → 详细设计 → 编码 → 测试"的软件过程。

### 1.3 定义与术语

| 术语 | 说明 |

## 2. 技术可行性

### 2.1 技术方案

| 层面 | 技术选型 | 说明 |
|---|---|---|
| 前端框架 | React 18 + TypeScript | 函数组件 + Hooks,类型安全 |
| 构建工具 | Vite 7 | 开发启动快,产物打包体积可控 |
| 样式 | Tailwind CSS 4 + shadcn/ui | 原子化样式 + 基础组件,无需自定义 UI 库 |
| 图表 | ECharts 5 | 柱状图 / 折线图,按需引入控制包体 |
| 路由 | react-router-dom 7 | SPA 路由与跨页参数传递 |
| 数据 | 静态 JSON(mock) | 演示阶段;服务层(api.ts)已隔离,可无缝替换真实 API |
| 部署 | 静态托管(Netlify 等) | 纯前端项目,无需服务器 |

上述技术均为业界成熟的开源方案,文档与社区资源丰富,不存在关键技术风险。

### 2.2 数据可行性

- **演示阶段**:由 `scripts/generate-mock.mjs` 程序化生成 20 种产品 × 10 个市场 × 90 天 = 18,000 条价格记录,规模可控、可复现;
- **真实化路径**:农业农村部"全国农产品批发市场价格信息系统"、各地批发市场官网均公开发布每日行情,可作为后续真实数据源;项目已通过 `src/services/api.ts` 将数据访问与页面隔离,替换数据源**无需改动页面代码**(详见《数据说明》文档)。

### 2.3 关键技术风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| 真实数据源获取(网站结构变化/反爬) | 中 | 演示阶段使用 mock 数据,不影响系统交付;真实化时采用服务端代理或官方数据接口 |
| prices.json 体积(约 1.4MB)影响首屏 | 低 | 服务层内存缓存只请求一次;构建后配合 gzip 传输;真实化后改服务端过滤 |
| ECharts 引入导致包体膨胀 | 低 | 按需注册组件(BarChart/LineChart 等),仅引入所需模块 |

### 2.4 技术可行性结论

**可行。** 全部技术栈为成熟开源方案,开发与部署环境零门槛,项目规模(3 个页面、约 1300 行源码)在单人开发能力范围内。

## 3. 经济可行性

### 3.1 开发成本

| 成本项 | 估算 | 说明 |
|---|---|---|
| 开发工具 | 0 元 | VS Code、Node.js、Git 均为免费开源 |
| 依赖库许可费 | 0 元 | React/MIT、ECharts/Apache-2.0、Tailwind/MIT 等许可均免费 |
| 人力成本 | 1 人 × 约 3 周 | 课程设计工作量,无外部人力支出 |
| 测试与部署 | 0 元 | 静态托管平台免费层 |

### 3.2 运行与维护成本

- 静态托管免费层即可满足演示与课程验收需求;
- 纯前端项目无服务器运维负担;
- 数据为静态文件,重新生成脚本一条命令即可更新。

### 3.3 预期收益

- **课程收益**:完整软件工程文档与实现,满足课程设计要求;
- **社会价值**:填补小型农产品比价工具空白,对采购者与小型商户有实用价值;
- **扩展潜力**:可接入真实行情后发展为信息服务平台(广告/订阅/数据服务)。

### 3.4 经济可行性结论

**可行。** 开发、运行成本接近零,风险极低,收益以课程与实用价值为主,投入产出比合理。

## 4. 操作可行性

### 4.1 用户特征

目标用户为普通消费者、餐饮采购人员、小型商户与农业相关人员,无需计算机专业知识,只需会使用浏览器。

### 4.2 易用性设计

- 零安装:浏览器访问即用;
- 首页提供**搜索、分类入口、异动榜单**三条路径直达分析页,学习成本低;
- 筛选交互直观(勾选产品/市场、单选日期/区间),图表随筛选实时刷新;
- **移动端适配**:导航折叠为汉堡菜单、布局自适应小屏;
- 跨页跳转携带 URL 参数,刷新后选择不丢失,链接可直接分享。

### 4.3 操作可行性结论

**可行。** 交互模式与主流 Web 应用一致,用户无需培训即可上手。

## 5. 法律与数据合规可行性

- 演示数据由脚本**程序化生成**,不涉及真实行情版权与任何个人信息,合规风险为零;
- 系统不采集、不存储任何用户数据,无隐私合规负担;
- 后续接入真实数据时,需遵守数据来源网站的使用条款(仅使用公开发布的行情数据,注明来源);
- 全部依赖库许可(MIT / Apache-2.0)允许自由使用与分发。

**结论:可行。**
