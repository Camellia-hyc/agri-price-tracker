# 核心代码讲解

> **本文档目的**:挑选关键文件逐段讲解,每个文件按"**输入是什么 → 做了什么处理 → 输出是什么**"组织,帮助读者快速读懂核心实现。代码片段均摘自项目源码(有节选标注)。

## 1. src/services/api.ts — 数据服务层

**输入**:`PriceQuery`(可选的产品 ID 列表、市场 ID 列表、起止日期);数据源为 `public/mock/` 下三个 JSON。

**处理**:

```ts
// 后期替换真实 API 时只需改这个文件
const MOCK_BASE = `${import.meta.env.BASE_URL}mock`

let pricesCache: PriceRecord[] | null = null

async function fetchJson<T>(path: string): Promise<T> {
  const res = await fetch(`${MOCK_BASE}/${path}`)
  if (!res.ok) {
    throw new Error(`加载 ${path} 失败:${res.status}`)
  }
  return res.json()
}

export function getProducts(): Promise<Product[]> {
  return fetchJson<Product[]>("products.json")
}

export function getMarkets(): Promise<Market[]> {
  return fetchJson<Market[]>("markets.json")
}

// prices.json 约 1MB,只请求一次,后续查询在内存过滤
export async function getPrices(query: PriceQuery = {}): Promise<PriceRecord[]> {
  if (!pricesCache) {
    pricesCache = await fetchJson<PriceRecord[]>("prices.json")
  }
  const { productIds, marketIds, startDate, endDate } = query
  return pricesCache.filter((r) => {
    if (productIds?.length && !productIds.includes(r.productId)) return false
    if (marketIds?.length && !marketIds.includes(r.marketId)) return false
    if (startDate && r.date < startDate) return false
    if (endDate && r.date > endDate) return false
    return true
  })
}
```

三个要点:

1. **通用请求函数 `fetchJson<T>`**:统一拼接路径、检查 `res.ok` 并抛出中文错误信息,泛型保证返回类型;
2. **模块级缓存 `pricesCache`**:prices.json(约 1.4MB)只在第一次调用时下载,之后所有查询直接对内存数组 `filter`。三个页面共享这一份缓存,因此价格数据整个会话只请求一次;
3. **内存过滤**:四个条件依次判断,未提供的条件自动跳过。日期比较直接使用字符串比较——因为日期统一为 `YYYY-MM-DD` 格式,字典序 = 时间序。

**输出**:`Promise<Product[]>` / `Promise<Market[]>` / `Promise<PriceRecord[]>`(过滤后的价格记录)。

## 2. src/components/charts/EChart.tsx — 图表底层封装

**输入**:`option: EChartsOption`(图表配置)与 `height`(默认 360)。

**处理**(两个 effect 各司其职):

```tsx
// 按需注册,控制打包体积
echarts.use([BarChart, LineChart, GridComponent, LegendComponent,
  TooltipComponent, CanvasRenderer])

export default function EChart({ option, height = 360 }: EChartProps) {
  const containerRef = useRef<HTMLDivElement>(null)
  const chartRef = useRef<echarts.ECharts | null>(null)

  // 初始化/销毁:整个生命周期只执行一次
  useEffect(() => {
    const el = containerRef.current
    if (!el) return
    const chart = echarts.init(el)
    chartRef.current = chart
    const onResize = () => chart.resize()
    window.addEventListener("resize", onResize)
    return () => {
      window.removeEventListener("resize", onResize)
      chart.dispose()
      chartRef.current = null
    }
  }, [])

  // option 变化时更新
  useEffect(() => {
    // notMerge 避免筛选切换时旧系列残留
    chartRef.current?.setOption(option, { notMerge: true })
  }, [option])

  return <div ref={containerRef} style={{ height, width: "100%" }} />
}
```

设计意图:

- **按需注册**:只 import 本项目用到的 Bar/Line 图表与 Grid/Legend/Tooltip 组件,避免全量 echarts 进包;
- **init 与 setOption 分离**:`echarts.init` 开销大,放在空依赖 effect 中只执行一次;筛选变化只触发第二个 effect 更新 option;
- **`notMerge: true`**:默认的 setOption 是合并模式,切换筛选条件时(如产品从 3 个变 1 个)旧系列会残留在图上;`notMerge` 让每次配置整体替换;
- **resize 监听 + dispose 清理**:窗口缩放自动重绘;组件卸载时移除监听、销毁实例,防止内存泄漏。

**输出**:一个自适应的 ECharts 画布(div),业务层只关心 option。

## 3. 统计卡片:StatCards.tsx + TrendAnalysis.tsx 的聚合

统计卡片的数值**不在卡片组件内计算**——`StatCards.tsx` 是纯展示组件,聚合发生在趋势页。

**输入(聚合部分,`TrendAnalysis.tsx` 节选)**:`allPrices`(全量记录)+ 选中产品/市场 + `startDate`(由时间范围倒推)。

```tsx
const { dates, stats } = useMemo(() => {
  // 按日期聚合选中市场+产品的价格
  const byDate = new Map<string, Map<string, number>>()
  for (const r of allPrices) {
    if (r.date < startDate) continue
    if (r.marketId !== selectedMarketId) continue
    if (!selectedProductIds.includes(r.productId)) continue
    let m = byDate.get(r.date)
    if (!m) { m = new Map(); byDate.set(r.date, m) }
    m.set(r.productId, r.price)
  }
  const sortedDates = [...byDate.keys()].sort()
  dates.push(...sortedDates)

  for (const p of selectedProducts) {
    const values = sortedDates.map((d) => byDate.get(d)?.get(p.id) ?? null)
    const nums = values.filter((v): v is number => v !== null)
    if (nums.length === 0) continue
    const first = nums[0]
    const last = nums[nums.length - 1]
    stats.push({
      product: p,
      values,
      latest: last,
      max: Math.max(...nums),
      min: Math.min(...nums),
      avg: nums.reduce((s, v) => s + v, 0) / nums.length,
      changePct: ((last - first) / first) * 100,
    })
  }
  return { dates, stats }
}, [allPrices, startDate, selectedMarketId, selectedProductIds, selectedProducts])
```

处理要点:

1. 单次遍历 `allPrices`,按"日期 → (产品 → 价格)"两级 Map 聚合,把 18000 条记录压成小结构;
2. 每个产品得到与 `sortedDates` 对齐的 `values` 数组,缺数据的日期为 `null`(折线图断点);
3. `changePct = (末价 − 首价) / 首价 × 100`,即**区间涨跌幅**;`max/min/avg` 是区间统计。

**输入(展示部分,`StatCards.tsx` 节选)**:`data: StatCardData[]`。红涨绿跌逻辑:

```tsx
{data.map((d) => {
  const up = d.changePct > 0
  const down = d.changePct < 0
  return (
    <Card key={d.product.id}>
      ...
      {/* 国内行情习惯:红涨绿跌 */}
      <div className={cn(
        "inline-flex items-center gap-1 text-sm font-medium",
        up && "text-destructive",          // 红
        down && "text-primary",             // 绿
        !up && !down && "text-muted-foreground", // 持平灰
      )}>
        {up ? <TrendingUp className="h-4 w-4" />
          : down ? <TrendingDown className="h-4 w-4" />
          : <Minus className="h-4 w-4" />}
        {up ? "+" : ""}
        {d.changePct.toFixed(1)}%
        ...
      </div>
      {/* 最高 / 最低 / 均价三格 */}
    </Card>
  )
})}
```

**输出**:每产品一张卡片——最新价(大号)、区间涨跌(带涨跌箭头与颜色)、最高/最低/均价三格,响应式栅格(1/2/3 列)。

## 4. src/components/compare/CompareTable.tsx — 明细表最低/最高高亮

**输入**:`data: CompareDatum[]`(每项 = 市场 + 该市场各产品价格)、`products: Product[]`(列)。

**处理**:

```tsx
// 每列的最低价/最高价,用于标色
const colMinMax = useMemo(
  () =>
    products.map((p) => {
      const prices = data.map(
        (d) => d.prices.find((x) => x.product.id === p.id)?.price ?? 0,
      )
      return { min: Math.min(...prices), max: Math.max(...prices) }
    }),
  [data, products],
)
```

单元格渲染时的判定:

```tsx
{d.prices.map((x, i) => {
  const { min, max } = colMinMax[i]
  const highlight = min !== max && x.price !== null
  return (
    <TableCell
      key={x.product.id}
      className={cn(
        "text-right tabular-nums",
        highlight && x.price === min && "font-semibold text-primary",     // 最低 → 绿
        highlight && x.price === max && "font-semibold text-destructive", // 最高 → 红
      )}
    >
      {x.price === null ? "—" : x.price.toFixed(2)}
    </TableCell>
  )
})}
```

设计要点:

1. **按列计算**:最高/最低是"同一产品在不同市场间"的列内比较(而非全表),符合"哪里最便宜/最贵"的业务语义;
2. **`min !== max` 防全亮**:若某列所有市场价格完全相同,整列既是最低也是最高,此时不高亮,避免满屏颜色;
3. `tabular-nums` 等宽数字保证价格列对齐。

**输出**:市场行 × 产品列的明细表,含底部"均价"行(`colAvg` 对每列求算术平均)。

## 5. src/lib/date.ts — 日期工具

**输入**:`dateStr`(YYYY-MM-DD 字符串)与偏移天数 `days`。

```ts
// YYYY-MM-DD 加减天数,返回同格式字符串
export function shiftDate(dateStr: string, days: number): string {
  const d = new Date(dateStr + "T00:00:00")
  d.setDate(d.getDate() + days)
  const y = d.getFullYear()
  const m = String(d.getMonth() + 1).padStart(2, "0")
  const day = String(d.getDate()).padStart(2, "0")
  return `${y}-${m}-${day}`
}
```

处理:拼接 `T00:00:00` 按**本地时区**解析(避免 `new Date("YYYY-MM-DD")` 被按 UTC 解析导致跨日偏移),加减天数后补零格式化回原格式。

**输出**:同格式的日期字符串。用途:趋势页由"最新日 − (rangeDays − 1)"倒推区间起点,如近 30 天即 `shiftDate(maxDate, -29)`。

## 7. 补充说明

- **`src/lib/utils.ts`** 的 `cn()` 是 shadcn/ui 约定工具(`clsx` + `tailwind-merge`),用于合并条件类名,如上文所有 `cn(...)` 调用;
- **`src/components/shared/ProductPicker.tsx`** 被对比页与趋势页共用:分类 Tab 过滤 + 产品 chips 多选,`max` 由调用方传入(两页均为 3),达到上限后未选中项禁用;
- **页面数据加载统一模式**:`Promise.all([getProducts(), getMarkets(), getPrices()])` + `cancelled` 标志(组件卸载后不再 setState),`error` state 控制失败态展示。
